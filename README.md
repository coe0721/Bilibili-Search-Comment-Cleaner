# B站搜索与评论净化

一个运行在 Tampermonkey 中的 Bilibili 网页增强脚本，重点解决两件事：

- 搜索页：对明确无关、低播放、低点赞播放比以及广告内容进行隐藏或淡化。
- 评论区：过滤低质量评论，并按点赞数、回复数或综合互动排序。

当前版本：`0.18.0`

## 安装

1. 在 Edge、Chrome 或 Firefox 安装正式版 Tampermonkey。
2. 点击下面的安装链接。
3. Tampermonkey 打开安装页后，检查权限并点击“安装”。
4. 刷新 Bilibili 页面，点击右下角粉色“评”按钮进行设置。

**[安装或更新脚本](https://raw.githubusercontent.com/coe0721/Bilibili-Search-Comment-Cleaner/main/bilibili-search-comment-cleaner.user.js)**

首次从旧版手工脚本切换时，也可以复制 [`bilibili-search-comment-cleaner.user.js`](./bilibili-search-comment-cleaner.user.js) 的全部内容，覆盖 Tampermonkey 中的旧代码并保存。

## 主要功能

- 评论低赞、短内容、低等级、重复套话和自定义关键词组合过滤。
- 评论按点赞数、回复数或综合互动排序。
- 默认采用“分批排序，不回跳”，新加载评论不会跳到已经读过的位置前面。
- 视频页、动态展开评论区和动态详情页均可处理。
- 搜索结果广告、最低播放量、最低点赞播放比和相关度检查。
- 可选匿名读取公开的视频标签，用于救回角色名、二创等标题不完整但实际相关的视频。
- 评论和搜索的淡化后可见度可分别输入 `1–100%`。
- 鼠标移到淡化内容上时显示具体原因。
- 设置保存在 Tampermonkey 专用存储中，刷新页面不会丢失。

## 安全与隐私

- 不读取、导出或上传 Cookie、账号凭证、搜索历史或评论内容。
- 不使用第三方 AI 服务，也不需要 API Key。
- 默认只处理页面中已经加载的内容。
- 仅当用户启用“点赞播放比”或“视频标签复核”时，匿名访问 Bilibili 的公开接口。
- 网络权限只允许 `api.bilibili.com`。
- 不包含 `eval`、远程执行代码、WebSocket 或第三方统计。

完整说明请查看 [安装与功能说明](./docs/安装说明.md)。

## 测试

需要 Node.js 22 或更新版本：

```bash
npm test
```

测试覆盖设置迁移、评论质量判断、排序稳定性、搜索相关度、请求限制和脚本安全约束。

## 已知限制

- 脚本只能排序 Bilibili 当前已经加载的评论，不会为了获取全量评论而批量请求接口。
- Bilibili 页面结构更新后，个别选择器可能需要同步调整。
- 搜索相关度采用保守策略：允许漏过少量无关结果，优先避免误伤相关内容。
